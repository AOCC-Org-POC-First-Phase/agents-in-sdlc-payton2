🎮 How to Play

📋

Game Rules

  • • Fill each row with numbers 1-9 (no repeats)
  • • Fill each column with numbers 1-9 (no repeats)
  • • Fill each 3×3 box with numbers 1-9 (no repeats)
  • • Complete all cells to win the puzzle!
⌨️

Controls

  • • Click on any cell to select it
  • • Type 1-9 to fill the selected cell
  • • Delete/Backspace to clear a cell
  • • Arrow Keys to navigate the grid

💫 Pro Tips

🧠 Strategy: Start with rows/columns that have the most numbers filled
⚡ Speed: Use keyboard navigation for faster input
