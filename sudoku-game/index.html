Sudoku Game

Challenge your mind with this classic puzzle game!

How to Play

Rules:

  • Fill each row with numbers 1-9
  • Fill each column with numbers 1-9
  • Fill each 3×3 box with numbers 1-9
  • No number can repeat in any row, column, or box

Controls:

  • Click on a cell to select it
  • Type a number (1-9) to fill the cell
  • Press Delete or Backspace to clear a cell
  • Use the buttons above for game controls
